# Asset register — Skyfall Legends

Every asset in the project is original or procedurally generated. There are no
third-party textures, models, sounds, or fonts. No asset is a placeholder for
protected content; where an asset is provisional (e.g. icon SVG), it is labeled
as such and its status is tracked here.

## Code (MIT, see LICENSE)

- `game/src/**` — 31 GDScript modules (`class_name`)
- `game/scenes/boot.tscn`, `dedicated_server.tscn`
- `game/tests/**` — unit + integration suite
- `tools/build/gen_sfx.py`, `tools/build/gen_class_cache.py`
