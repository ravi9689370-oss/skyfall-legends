# Brand guidelines — Skyfall Legends

## Name and wordmarks

- **Product:** Skyfall Legends
- **Descriptor:** "original online-multiplayer battle royale prototype" (Android-first, Godot 4.7)
- **Package ID (Android):** `com.skyfalllegends.sandbox` (debug) /
  `com.skyfalllegends.game` (release preset) — these placeholder package IDs
  must be replaced before any public release.

## Visual identity

- All visuals are **code-procedural**; there are no imported texture or model
  assets. The only authored image is `game/images/icon.svg` (original project
  icon; placeholder-grade vector art, labeled as such).
- Boot splash color (from `project.godot`): deep navy `#0B1320`
  (0.043, 0.074, 0.121, alpha 1).
- No logo lockups or wordmark artwork exist yet; do not derive marks from
  third-party games.

## Voice

- Plain, honest engineering language. Features are described only as
  implemented-and-tested; plans are labeled plans.
- Bots are always visibly marked (`AI_###`, roster tag `[BOT]`) and never
  presented as human players.

## Prohibited

- No references to, or assets copied from, protected battle-royale titles or
  other IP.
- No "official" claims beyond this repository; no endorsement language.
