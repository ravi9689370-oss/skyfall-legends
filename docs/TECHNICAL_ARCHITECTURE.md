# Technical architecture — Skyfall Legends

## Project layout

Single Godot 4.7 project at repo root (`project.godot`, `config_version=5`).
One binary serves both client and dedicated server:

- Client main scene: `res://game/scenes/boot.tscn` → menu → lobby → match view.
- Server scene: `res://game/scenes/dedicated_server.tscn` → `server_main.gd`
  → `NetServer` (headless, no viewport).

31 `class_name` scripts (cache generated by `tools/build/gen_class_cache.py`
because the editor crashes in this host — see `docs/ENVIRONMENT_AUDIT.md`).

## Module map

| Directory | Modules (class_name) | Responsibility |
|-----------|----------------------|----------------|
| `game/src/core` | Protocol, WeaponsDB, ItemsDB, CharactersDB, Damage, Inventory, MatchRules, Names, GameLog, Logger→GameLog | Databases, pure math, wire format, logging |
| `game/src/map` | MapData, MapGen | Analytic island, loot points, flight path, building AABBs |
| `game/src/match` | MatchSim, Zone, LootField, Combat, BotBrain, MatchEvents | Authoritative match: combat, zone, loot, elimination, bots |
| `game/src/net` | NetServer, NetClient, server_main | Sessions, lobbies, matchmaking, wire ops |
| `game/src/client` | FpsController, Mannequin, RemotePlayer, MatchView | Client-side prediction, rendering, input |
| `game/src/ui` | Hud, JoystickPad, LookPad, MenuScreen, LobbyScreen, ResultScreen | Screens and HUD |
| `game/src/game_root.gd` | GameRoot | Boot binding |

## Networking

- Transport: ENet UDP, one port (default 7777).
- Protocol: custom binary op codes over `StreamPeerBuffer` (little-endian).
  - Client → server: HELLO, LOBBY_CREATE/JOIN/BACK, SET_READY, INPUT (unreliable), FIRE (unreliable), USE_ITEM, PICKUP, RELOAD, SWITCH_WEAPON, SPECTATE, PING (unreliable).
  - Server → client: HELLO_OK, LOBBY_STATE/MSG, MATCH_START, SNAPSHOT, MATCH_EVENT, MATCH_END, SERVER_CLOSE/KICKED, PONG.
- Reliability: lifecycle packets reliable; input/snapshot/ping/fire unreliable.
- Rate limit: 70 messages/s per peer; 3 violations → kick (`s_kicked`).
- Server uses `SceneMultiplayer` + `ENetMultiplayerPeer` purely as a socket
  wrapper; **no scene replication is used**. Game state travels in the custom
  protocol only.

## Authority

`MatchSim` owns all state: positions (validated against movement caps),
damage (`Damage.apply`), inventory (`Inventory` validity checks, ammo caps),
loot claims (atomic first-claim), zone damage, eliminations, placement, and
MATCH_END. Clients send intent only.

## Rendering / assets

- Renderer: mobile, 1280×720 base, canvas_items stretch, expand aspect.
- No imported textures/models/audio. Visuals are code-procedural (mannequins,
  debug primitives). Icon is an original SVG.
- SFX: 12 original 16-bit mono 22050 Hz WAVs generated by
  `tools/build/gen_sfx.py`; not yet wired into gameplay.

## Physics / timing

- 30 physics ticks/sec; `MatchSim.tick(delta)` runs on the server's `_process`
  (game loop), snapshots broadcast at 8 Hz per viewer.
